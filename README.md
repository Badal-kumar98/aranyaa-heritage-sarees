## 🌟 Overview

**Aranyaa** is an artisanal e-commerce web platform celebrating India's ancient weaving traditions. Featuring pure mulberry silk Kanjivarams, gold zari Banarasis, and airy Chanderi weaves. Designed with deep crimson, ivory, and regal antique gold aesthetics.

### ✨ Key Features
- **Redux Toolkit Architecture**: Centralized cart slices, item counter selectors, and checkout state synchronizations.
- **Curated Textile Collections**: Filter by heritage weave cluster (Kanjivaram, Banarasi, Chanderi, Tussar, Organza).
- **Weave Craft Documentation**: Interactive masterclass essays on Jacquard pit-looms, real silver/gold electroplated zari testing, and silk mark certifications.
- **Editorial Lookbook & Flatlays**: High-resolution gallery displaying drape flows, border selvages, and rich pallu intricacies.
- **Complete Shopping Workflow**: Search overlays, wishlist persistence, promo code engine, and multi-step simulated checkout.

## 🛠 Tech Stack

- **Framework**: React 19, TypeScript, Vite
- **State Management**: Redux Toolkit, React-Redux
- **Styling**: Tailwind CSS v4
- **Animation**: Framer Motion
- **Icons**: Lucide React
- **Routing**: React Router v7 (`HashRouter`)

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/Badal-kumar98/aranyaa-heritage-sarees.git

# Navigate into directory
cd aranyaa-heritage-sarees

# Install dependencies
npm install

# Run dev server
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```
